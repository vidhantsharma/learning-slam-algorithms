# SLAM Algorithms (EKF-SLAM starter)

This repo is a small learning-focused structure for SLAM. The Kalman filter utilities live in one folder and are reused by the EKF-SLAM module. A simple 2D scenario runs in C++ and writes CSV output, which you can visualize with Python.

## Structure


```
slam_core/
  utils/                # Matrix utilities
  ekf_slam/             # EKF-SLAM implementation (library)
examples/
  ekf_slam_demo.cpp     # Demo runner for EKF-SLAM
slam_viz/
  plot_ekf_slam.py      # Visualization for the demo output
requirements.txt        # Python requirements for visualization
output/                 # Generated by the demo
```

## Build the C++ demo


```bash
mkdir -p build
cmake -S . -B build
cmake --build build
```

Run the demo from the repo root (output will be in ./output):

```bash
./build/examples/ekf_slam_demo
```

It writes:

- `output/trajectory.csv`
- `output/landmarks.csv`
- `output/landmark_estimates.csv`
- `output/observations.csv`

## Plot the results (Python)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r slam_viz/requirements.txt
python slam_viz/plot_ekf_slam.py --show

For animation with uncertainty ellipses:

python slam_viz/plot_ekf_slam.py --animate --show

## One-command demo

```bash
./run_demo.sh --animate --show --steps 500
```
```

## Notes

- The EKF-SLAM demo uses a small synthetic world with 5 landmarks.
- If `slam_viz/requirements.txt` does not exist, it will be created automatically with the required packages.
- The filter math uses a lightweight matrix implementation under `cpp/kalman_filters/`.
- This is meant as a learning baseline, not a production SLAM system.
